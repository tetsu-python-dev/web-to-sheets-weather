# MusicBrainz API学習版

添付の `main.py` を保存した別プロジェクトです。公開アーティストIDと学習コードを残し、個人のスプレッドシートIDだけ `YOUR_MUSIC_SPREADSHEET_ID` に置換しています。既存のMac上のプロジェクトは変更していません。

既存の環境・認証ファイルでこれまで通り学習できます。ZIPのこのフォルダを単独で動かす場合は、専用の `credentials.json` と `token.json` をこのフォルダに配置し、コードのスプレッドシートIDを設定してください。ターミナルの作業ディレクトリをこのフォルダにして実行します。

この学習版は元の実装を保存したもので、期限切れトークンの更新などの改善は気象版に実装しています。気象版は別のスプレッドシートを使います。
